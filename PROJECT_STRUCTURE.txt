Firewall Action Classification System — NetSentry (scikit-learn)

Main source:
  app.py                          Flask prediction API and site
  model_service.py                Loads trusted joblib sklearn model / predicts
  data_pipeline.py                Dataset validation, deduplication, split hygiene
  train_model.py                  sklearn Pipeline training, CV and metrics
  requirements.txt               Flask, pandas, scikit-learn, joblib

Inputs and generated files:
  data/log2_cleaned.csv           Classmate supplied cleaned dataset (committed)
  data/log2.csv                   Optional original UCI file (not included)
  data/data_quality_report.json   Generated data quality report (Git ignored)
  data/evaluation_report.json     Generated evaluation metrics (Git ignored)
  model/firewall_random_forest.joblib  Generated sklearn Pipeline (Git ignored)

Supporting files:
  notebooks/DataCleaning.ipynb    Classmate's Colab reference (unchanged)
  tests/test_preprocessing.py     Cleaning and split unit tests
  tests/test_api.py               Flask endpoint unit tests
  tests/test_model_service.py     scikit-learn model roundtrip tests
  templates/index.html            NetSentry web interface
  static/style.css                Responsive dark-themed UI
  static/app.js                   Browser-based prediction history
  setup_project.bat               Create venv and install Python dependencies
  train_model.bat                 Train sklearn model
  start_website.bat               Start Flask website
  verify_project.bat              Check required files

The original pure-Python Random Forest is no longer used. The notebook and
website share the sklearn RandomForestClassifier configuration but still differ
in cleaning and test records. Read README.md before citing accuracy or confidence.

Firewall Action Classification System - current project structure

app.py                          Flask prediction API and website
forest_model.py                 Educational pure-Python Random Forest
data_pipeline.py                Validates data, removes contradictions, splits safely
train_model.py                  Validation-based selection and held-out evaluation
requirements.txt               Flask only (website/runtime)
data/log2_cleaned.csv           Classmate-provided dataset (included)
data/log2.csv                   Optional original UCI file (not included)
data/data_quality_report.json   Generated audit of data-quality decisions
data/evaluation_report.json     Generated validation and test-set metrics
model/firewall_random_forest.json  Generated deployable custom JSON model
notebooks/DataCleaning.ipynb    Classmate's exploratory scikit-learn notebook
tests/test_preprocessing.py     Standard-library regression tests
templates/index.html            Web interface
static/style.css                Website styling
static/app.js                   Dashboard and browser-local prediction history
setup_project.bat               Creates .venv and installs Flask
train_model.bat                 Trains on cleaned CSV (or original fallback)
start_website.bat               Starts local Flask website after training
verify_project.bat              Checks supporting project files

The supplied notebook is reference material; the Flask app does not load
its scikit-learn pickle model. Read README.md for setup, methodological
limitations, and preprocessing details.

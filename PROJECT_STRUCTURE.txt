This folder itself is the project root. After extraction, these files should be directly visible in VS Code Explorer (do not open a nested project folder).

app.py                         Flask website/API
forest_model.py                Pure-Python Random Forest implementation
train_model.py                 Loads data/log2.csv, trains and evaluates the model
requirements.txt                Flask dependency only
setup_project.bat               Creates .venv and installs Flask
train_model.bat                 Trains the model from data/log2.csv
start_website.bat               Starts the local Flask website
verify_project.bat              Checks files and generated outputs
data/log2.csv                  Copy the original UCI dataset here
 data/evaluation_report.json    Generated by training
model/firewall_random_forest.json Generated by training
templates/index.html            Website layout
static/style.css                Website styling
static/app.js                   Form behavior and browser-local history

The ZIP archive does not include .venv, model outputs, or log2.csv. They are created/added during setup as described in README.md.
